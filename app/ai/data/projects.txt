Allwecure 
1. Executive Summary and Introduction
Allwecure is a robust B2B/B2C pharmaceutical and medical supply marketplace platform 
designed to streamline the procurement process for medical products. The platform 
connects pharmaceutical sellers with a diverse range of buyers, including pharmacies, 
hospitals, patent medicine vendors, and regular consumers.
This documentation provides a comprehensive overview of the entire Allwecure ecosystem, 
which is composed of three primary components: a modern Web Frontend, a dedicated 
Mobile Application, and a centralized Backend API with an Admin Panel.
2. System Architecture Overview

8. Key Implementation Notes
8.1. Order ID and Pricing

• 
Price Mapping:
• 
Unit Price (
price ): Final selling price (what buyer pays) = originalPrice - discount
• 
Original Price (
originalPrice ): Base price before any discount (shown crossed out).
• 
Discount: Amount subtracted from originalPrice
• 
Cost Price: Seller's internal cost, not displayed to buyers.
8.2. Bulk Import Workflow
The bulk import process is designed to ensure data quality and seller review:
1. Seller uploads a CSV file.
2. Products are parsed and a preview is displayed.
3. All imported products are saved as drafts (
isPublished: false ).
4. The seller must manually review and publish each product via the Seller Dashboard.
